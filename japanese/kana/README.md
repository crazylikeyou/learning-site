# 五十音学习站

一个纯静态的日语五十音学习网站。**双击 `index.html` 就能用**——不需要安装、不需要联网、不需要服务器。

## 包含的内容

完整的 104 音，平假名和片假名两套各一遍：

| 区块 | 数量 | 说明 |
| --- | --- | --- |
| 清音 | 46 | あ〜ん，五十音图主体（含 や行、わ行的空格，与真实图表一致） |
| 浊音・半浊音 | 25 | が行・ざ行・だ行・ば行・ぱ行（含少用的 ぢ・づ） |
| 拗音 | 33 | きゃ〜ぴょ，11 行 × 3 |

每个假名都带：罗马音（Hepburn 式）、笔画数（平/片分开）、一个例词（平假名例词 + 片假名例词）、
以及易错音的发音要点（し・ち・つ・ふ・ら行・ん・を・じ/ぢ・ず/づ・は/へ 助词读音等）。

## 五个功能

1. **五十音图** —— 点假名听发音、看例词、标记「已掌握」；点**行标题**连读一整行，点**段标题**连读一整段。
2. **卡片记忆** —— 翻卡自测，可选范围（清音/浊音/拗音/全部）、顺序或随机、「只练未掌握的」。键盘：空格翻转、← 还不会、→ 记住了。
3. **闯关测验** —— 三种题型（假名→罗马音 / 罗马音→假名 / 听发音→假名），10 题一轮，结算给错题清单，可以「只练错题」。干扰项优先取同一行的假名（例如考 ひ 时给 は・ふ・へ・ほ），练的是真辨音。
4. **书写练习** —— 米字格 + 浅灰描红，鼠标或手指直接写，支持撤销、清空、切换假名。
5. **发音要点** —— 五个元音口型、五个最容易读错的假名、长音、促音与拨音、声调入门、4 周记忆计划。

学习进度、语音、语速、深浅色都记在浏览器本地（localStorage），关掉再打开还在。

## 发音说明

发音用的是浏览器自带的语音合成（Web Speech API），本机已检测到 4 个日语语音：
Haruka（默认）、Ayumi、Ichiro、Sayaka，可在右上角切换并调语速。

如果换一台电脑没有日语语音包，页面会给出提示。解决办法：
Windows「设置 → 时间和语言 → 语言和区域 → 添加语言」添加**日语**并勾选语音包，重启浏览器即可。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式（含深色模式、手机适配、打印样式） |
| `data.js` | 全部假名数据、例词、发音要点文本（想改内容改这里即可） |
| `app.js` | 交互逻辑 |

小技巧：在五十音图页面直接按 `Ctrl+P` 打印，会自动隐藏所有按钮和面板，只留干净的速查表。
