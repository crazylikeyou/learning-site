# 二极管课程 circuitikz 图

本目录保存第 3 章课堂同步课程的示意图：

| 文件 | 内容 |
|---|---|
| `diode-loadline` | 简单二极管电路与负载线图解 |
| `diode-halfwave` | 半波整流电路与输出波形 |
| `diode-limiter` | 限幅电路与钳位波形 |
| `diode-clamp` | 钳位电路与稳态波形 |
| `diode-small-signal` | Q 点切线与小信号电阻等效 |
| `diode-switch` | 理想二极管开关电路例题 |
| `diode-forward-circuit` | 正向模型计算练习电路 |

运行 `build.ps1` 可使用 XeLaTeX 重新生成全部 PDF 和 300 dpi PNG。
