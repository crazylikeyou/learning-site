补充课 · 电阻的等效与输入电阻

对应考试大纲第二章第 1、3 条：电阻的串并联等效、无源一端口的输入电阻。

2026-10-26 · 预计 20 分钟 · 补充内容

一、"等效"到底是什么意思

两个电路对外等效，指的是：从端口看进去，电压和电流的关系完全一样。内部结构可以完全不同，只要端口上满足同一个 $u=Ri$，外部电路就分辨不出来。

所以等效是对外等效，不是内部等效。求等效电阻时，你只关心"从这两个端子看进去是多少欧"，中间怎么连是过程。

二、串并联：先弄清谁和谁连在一起

连接方式判据等效
串联两个电阻只有一个公共节点，中间没有分支$R = R_1 + R_2$
并联两个电阻两端分别接在同一对节点上$\dfrac{1}{R}=\dfrac{1}{R_1}+\dfrac{1}{R_2}$，两电阻时用 $\dfrac{R_1R_2}{R_1+R_2}$

看复杂电路时容易看错连接关系。一个可靠的办法是给节点编号：把导线能直接连通的地方都算同一个节点，标上同一号码，然后再看每个电阻夹在哪两个编号之间。

两个电阻"看起来挨着"，不等于串联。串联的唯一判据是它们之间没有第三个元件接出去。

三、两种能一眼看穿的电路

① 对称桥路——等电位点。 桥的四条臂电阻两两相等时，中间那条横跨的电阻两端电位相同，没有电流流过，可以直接去掉（也可以直接换成导线，结果一样）。

② 电桥平衡。 更一般的判据是对角乘积相等：

$$R_1 R_4 = R_2 R_3$$

满足时中间支路电流为零，等效为两条串联支路再并联。这个条件在解题时能省掉大量计算。

四、什么是输入电阻

无源一端口网络（内部没有独立源），从端口看进去的等效电阻，就叫输入电阻 $R_{in}$。求法和求等效电阻完全一样：从端口往里逐级串并联化简。

和大纲的对应关系：第二章第 1 条"电阻等效变换——串联、并联"给的是工具，第 3 条"无源一端口网络——输入电阻"给的是用途。考试里这两个通常合成一道题：求图示电路的输入电阻 $R_{ab}$。

四之二、电导：并联时更好用的写法

电导 $G = \dfrac{1}{R}$，单位西门子（S）。它描述"这条支路多容易通过电流"。

电阻并联要算倒数和，用电导直接相加：

$$G = G_1 + G_2 + \cdots \qquad\text{（并联）}$$

算完再取倒数变回电阻。串联时仍然用电阻相加，不要混着用。

例：$G_1 = 0.5\ \mathrm{S}$、$G_2 = 0.25\ \mathrm{S}$ 并联，$G = 0.75\ \mathrm{S}$，所以 $R = \dfrac{1}{0.75} = \dfrac{4}{3} \approx 1.33\ \Omega$。

验证一下：$G_1$ 对应 $2\ \Omega$，$G_2$ 对应 $4\ \Omega$，并联 $\dfrac{2\times4}{2+4} = \dfrac{4}{3}$ ✓ 两种算法一致。

老师笔记 2-4 的 (b) 就是这种题：三条支路并联，其中两条直接给电导 $G_1$、$G_2$。这时先把电导相加比换算成电阻再并联快得多。看到单位是 S 或者字母写成 $G$，就要立刻想到"相加"。

五、例题一：对称桥

四条臂都是 $3\ \Omega$，中间横跨 $6\ \Omega$，求 $R_{ab}$。

图 · 对称桥：四条臂相等，中间横跨 6 Ω

四臂相等，电路左右对称，c 点和 d 点电位相同——中间那条 $6\ \Omega$ 上没有电流。

把它去掉，电路变成上下两条串联支路再并联：

$$R_{ab} = (3+3) \parallel (3+3) = 6 \parallel 6 = 3\ \Omega$$

用平衡条件验证：$3 \times 3 = 3 \times 3$，平衡成立，中间支路确实无电流。

六、例题二：逐级化简

端口 a—b。$R_1 = 6\ \Omega$ 从 a 接到节点 n1；n1 经 $R_2 = 3\ \Omega$ 接到 b；n1 经 $R_3 = 2\ \Omega$ 接到 n2；n2 经 $R_4 = 4\ \Omega$ 接到 b。求 $R_{ab}$。

图 · 梯形网络，从离端口最远的一端开始化简

口诀：从离端口最远的地方往里收。离 a 最远的是 $R_4$。

$R_4$ 与 $R_3$ 串联（n2 到 b 之间只有这一条路，先看串联更直观）：$2 + 4 = 6\ \Omega$。

这条 $6\ \Omega$ 与 $R_2 = 3\ \Omega$ 并联（都接在 n1 与 b 之间）：

$$\frac{6 \times 3}{6+3} = 2\ \Omega$$

再与 $R_1 = 6\ \Omega$ 串联：

$$R_{ab} = 6 + 2 = 8\ \Omega$$

易错点：不要从 a 开始算。a 端是"总入口"，那里只能先串联一次；真正能化简的起点在最远端。

七、解答题

题 1（对称桥）

四条臂均为 $3\ \Omega$，中间横跨 $6\ \Omega$。求 $R_{ab}$，并说明为什么中间电阻可以去掉。

展开答案

四臂相等 → 电路对称 → 中间横跨电阻两端等电位 → 无电流 → 可去掉。

$$R_{ab} = (3+3)\parallel(3+3) = 6\parallel6 = 3\ \Omega$$

要点："等电位"这个说法必须能说出口，不能只写"对称所以去掉"。等电位才是无电流的原因。

题 2（逐级化简）

$R_1 = 12\ \Omega$ 从 a 到 n1；n1 经 $R_2 = 4\ \Omega$ 到 b；n1 经 $R_3 = 2\ \Omega$ 到 n2；n2 经 $R_4 = 2\ \Omega$ 到 b。求输入电阻 $R_{ab}$。

展开答案

从最远端开始：$R_3$ 与 $R_4$ 串联得 $2 + 2 = 4\ \Omega$。

与 $R_2 = 4\ \Omega$ 并联：$\dfrac{4 \times 4}{4+4} = 2\ \Omega$。

再与 $R_1$ 串联：$R_{ab} = 12 + 2 = 14\ \Omega$。

题 3（电桥平衡判断）

桥式电路：上臂 $R_1 = 2\ \Omega$、$R_2 = 4\ \Omega$；下臂 $R_3 = 1\ \Omega$、$R_4 = 2\ \Omega$；中间横跨一个电阻。判断电路是否平衡，并求 $R_{ab}$。

展开答案

平衡条件 $R_1R_4 = R_2R_3$：左边 $2 \times 2 = 4$，右边 $4 \times 1 = 4$，相等 → 平衡。

中间支路无电流，去掉后是两条串联支路并联：

$$R_{ab} = (2+4)\parallel(1+2) = 6\parallel3 = \frac{6\times3}{6+3} = 2\ \Omega$$

易错点：判平衡要算对角乘积，不是相邻乘积，也不是比值随便凑。$R_1R_4$ 对应的是这条对角线两端的两个电阻。

拓展（大纲外，仅供了解）：当四个臂都不成比例、桥不平衡时，中间的横跨电阻既不能去掉也不能当导线，需要用到 Y–Δ 变换。你老师的大纲只写了"串联、并联"，说明不考这一步；如果考试真出了不平衡桥，通常也会给出足够信息让你用节点法绕开。
