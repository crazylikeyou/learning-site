补充课 · 电源等效变换

对应考试大纲第二章第 2 条：实际电压源与实际电流源的等效变换。

2026-10-26 · 预计 20 分钟 · 老师笔记 2-11 那道题就靠它

一、为什么需要它

两个电压源并联，不能直接相加；两个电流源串联，也不能直接合并。可考试偏偏爱出这种电路。

办法是把它们统一成同一种模型：都换成电流源并联电阻，就能合并；或者都换成电压源串联电阻，就能合并。

二、两种模型怎么互换

实际电压源：理想电压源 $U_s$ 串联内阻 $R$。
实际电流源：理想电流源 $I_s$ 并联内阻 $R$。

两者对外完全等效，条件是：

$$I_s = \frac{U_s}{R} \qquad\text{或}\qquad U_s = I_s R$$

内阻 $R$ 不变，只是从"串联"挪到"并联"。

方向规则：电流源的箭头指向电压源的正极那一端。方向搞反，整个结果全反。

三、三条使用纪律

① 只对外等效，不对外等效内部。 变换后，外接部分看到的电压电流完全一样，但电源内部消耗的功率变了。所以题目问"电源发出多少功率"时，不能用变换后的电路去算。

② 理想电压源不能单独变换。 内阻为零时 $I_s = U_s/0$ 无穷大，没有意义；理想电流源同理（内阻无穷大）。必须有那个串联或并联的电阻才能换。

③ 变换是为了化简，不是为了好看。 目标是让"不能直接合并的电源"变成"能合并的并联电流源"或"能合并的串联电压源"。

四、例一：最简单的一次转换

$12\ \mathrm{V}$ 电压源串 $2\ \Omega$，转成电流源：

$$I_s = \frac{12}{2} = 6\ \mathrm{A}，\quad \text{并联 } 2\ \Omega$$

反过来，$6\ \mathrm{A}$ 并 $2\ \Omega$ 转回电压源就是 $12\ \mathrm{V}$ 串 $2\ \Omega$。同一件事，两种画法。

五、例二：两个电压源并联

$12\ \mathrm{V}$ 串 $2\ \Omega$ 与 $6\ \mathrm{V}$ 串 $3\ \Omega$ 并接在同一对端子上，求等效。

第一步，都转成电流源：

$I_{s1} = 12/2 = 6\ \mathrm{A}$，并 $2\ \Omega$；$I_{s2} = 6/3 = 2\ \mathrm{A}$，并 $3\ \Omega$。

第二步，同向电流源相加、电阻并联：

$$I_s = 6 + 2 = 8\ \mathrm{A}，\qquad R = \frac{2\times3}{2+3} = 1.2\ \Omega$$

第三步，转回电压源：

$$U_s = 8 \times 1.2 = 9.6\ \mathrm{V，内阻 } 1.2\ \Omega$$

如果一开始直接把 $12\ \mathrm{V}$ 和 $6\ \mathrm{V}$ 相加得 18 V，或者取平均，都是错的——并联电源不能直接加减。

六、例三：化简后再分流

$10\ \mathrm{V}$ 串 $2\ \Omega$ 与 $4\ \mathrm{V}$ 串 $2\ \Omega$ 并联，外接 $3\ \Omega$ 负载，求负载电流。

图 · 两个实际电压源并联，接 3 Ω 负载

转成电流源：$10/2 = 5\ \mathrm{A}$，$4/2 = 2\ \mathrm{A}$，两个 $2\ \Omega$ 并联。

合并：$I_s = 5 + 2 = 7\ \mathrm{A}$，$R = 2 \parallel 2 = 1\ \Omega$。

转回电压源：$U_s = 7 \times 1 = 7\ \mathrm{V}$，内阻 $1\ \Omega$。

接负载算电流：回路总电阻 $1 + 3 = 4\ \Omega$，

$$I = \frac{7}{4} = 1.75\ \mathrm{A}$$

四步：转 → 合 → 转 → 算。多电源题基本都这么走。

七、解答题

题 1

$12\ \mathrm{V}$ 串 $3\ \Omega$ 与 $6\ \mathrm{V}$ 串 $6\ \Omega$ 并接在同一对端子上。求对外等效的电压源参数，并写出中间每一步。

展开答案

转电流源：$12/3 = 4\ \mathrm{A}$，$6/6 = 1\ \mathrm{A}$。

合并：$I_s = 4 + 1 = 5\ \mathrm{A}$；$R = 3 \parallel 6 = 2\ \Omega$。

转回电压源：$U_s = 5 \times 2 = 10\ \mathrm{V}$，内阻 $2\ \Omega$。

要点：每一步都要写出来，考试按步给分。直接写"等效为 10 V、2 Ω"只拿结果分。

题 2

$24\ \mathrm{V}$ 串 $4\ \Omega$ 与 $8\ \mathrm{V}$ 串 $4\ \Omega$ 并联后，外接 $6\ \Omega$ 负载。用等效变换求负载电流。

展开答案

转电流源：$24/4 = 6\ \mathrm{A}$、$8/4 = 2\ \mathrm{A}$，两个 $4\ \Omega$ 并联。

合并：$I_s = 8\ \mathrm{A}$，$R = 4 \parallel 4 = 2\ \Omega$。

转回电压源：$U_s = 8 \times 2 = 16\ \mathrm{V}$，内阻 $2\ \Omega$。

接负载：$I = \dfrac{16}{2 + 6} = 2\ \mathrm{A}$。

题 3（易错）

用等效变换算出上题负载电流后，能否用变换后的电路去求"原来两个电压源各自发出的功率"？说明理由。

展开答案

不能。 等效变换只保证对外端口的电压电流关系相同，电源内部的工作状态完全变了。

变换前每个电源有自己的电流和功率；变换后合并成一个电源，原来的两个电源已经不存在了，无法反推各自的功率。

要算各电源功率，必须回到原电路：先求出各支路真实电流，再用 $P = UI$ 逐个算，并判断吸收还是发出。

和笔记 2-11 的关系：那道题做了三次变换（10 V/4 Ω→2.5 A、4 V/4 Ω→1 A、6 V/2 Ω→3 A），合并后转回电压源，最后用分流公式求目标电流。方法是同一套，只是步骤更多。多一步就多一个出错机会，所以每步都要写清楚方向。
