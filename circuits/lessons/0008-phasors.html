第 8 课 · 相量法

把正弦量变成复数，让微分方程退化成欧姆定律。

2026-10-22 · 预计 25 分钟 · 对应第八章

一、为什么要有相量

同一个正弦量有四个要素：幅值、角频率、初相、正负基准。但当电路里所有信号都同频时，角频率是共同的，可以暂时不管——真正区分各处的只有幅值和初相。

幅值加初相，正好就是复数的模和角。于是每个正弦量对应一个复数（相量），KCL、KVL、欧姆定律全部变回代数运算，不用再解微分方程。

两个约定，考试按这个来（你黑板上的写法）：

① 以 cos 为基准，正弦量写成 $u=U_m\cos(\omega t+\psi_u)$；
② 相量取有效值，大写字母加点，如 $\dot{U}=U\angle\psi_u$，其中 $U=U_m/\sqrt2$。

二、遇到 sin 先换算

$$\sin\theta = \cos(\theta - 90^\circ)$$

例如 $i = 10\sin(\omega t + 30^\circ)\ \mathrm{A}$，先写成 $10\cos(\omega t - 60^\circ)$，再取相量：$\dot I = \dfrac{10}{\sqrt2}\angle{-60^\circ}\ \mathrm{A}$。

这一步每年都有人错——直接把 $30^\circ$ 抄进去。等你确定课本用的是 cos 基准，sin 就必须减 90°。

三、三个元件在相量世界的"电阻"

元件时域关系相量关系复阻抗
电阻 $R$$u=Ri$$\dot U=R\dot I$$Z_R=R$
电感 $L$$u=L\dfrac{\mathrm di}{\mathrm dt}$$\dot U=j\omega L\dot I$$Z_L=j\omega L$
电容 $C$$i=C\dfrac{\mathrm du}{\mathrm dt}$$\dot U=\dfrac{\dot I}{j\omega C}$$Z_C=\dfrac{1}{j\omega C}=-j\dfrac{1}{\omega C}$

串联时阻抗直接相加：

$$Z = R + j\left(\omega L - \frac{1}{\omega C}\right) = R + j(X_L - X_C)$$

然后 $\dot U = Z\dot I$——和直流电路里的欧姆定律长得一模一样，只不过数字是复数。

四、例题（你课上的例 8-4）

已知 $i_s = 5\sqrt2\cos(10^3 t + 30^\circ)\ \mathrm{A}$，$R = 30\ \Omega$，$L = 0.12\ \mathrm{H}$，$C = 12.5\ \mu\mathrm{F}$，三者串联。求 $\dot U_{ad}$ 和 $\dot U_{bd}$。

第一步：算各元件的复阻抗。

$$\omega L = 10^3 \times 0.12 = 120\ \Omega,\qquad \frac{1}{\omega C} = \frac{1}{10^3 \times 12.5\times10^{-6}} = 80\ \Omega$$

$$Z_L = j120\ \Omega,\qquad Z_C = -j80\ \Omega,\qquad Z_R = 30\ \Omega$$

第二步：写出电流相量。 幅值 $5\sqrt2$，有效值 $5$；cos 基准，初相 $30^\circ$：

$$\dot I_s = 5\angle 30^\circ\ \mathrm{A}$$

第三步：逐段求电压。

$$\dot U_R = R\dot I = 30 \times 5\angle30^\circ = 150\angle30^\circ\ \mathrm{V}$$

$$\dot U_L = j120 \times 5\angle30^\circ = 120\angle90^\circ \times 5\angle30^\circ = 600\angle120^\circ\ \mathrm{V}$$

$$\dot U_C = -j80 \times 5\angle30^\circ = 80\angle{-90^\circ} \times 5\angle30^\circ = 400\angle{-60^\circ}\ \mathrm{V}$$

第四步：相量相加（必须转成直角坐标）。

$\dot U_R = 129.9 + j75$，$\dot U_L = -300 + j519.6$，$\dot U_C = 200 - j346.4$。

$$\dot U_{ad} = (129.9 - 300 + 200) + j(75 + 519.6 - 346.4) = 29.9 + j248.2\ \mathrm{V}$$

$$\dot U_{ad} = 250\angle83.1^\circ\ \mathrm{V}$$

而 $\dot U_{bd} = \dot U_L + \dot U_C$：

$$(-300 + 200) + j(519.6 - 346.4) = -100 + j173.2 = 200\angle120^\circ\ \mathrm{V}$$

关键动作：相量相加不能直接加幅值，必须先转成 $a + jb$ 再加，加完再转回极坐标。$150\angle30^\circ + 600\angle120^\circ$ 绝不等于 $750\angle150^\circ$——这是最常见、最致命的错误。

五、解答题

题 1（三问）

串联电路：$R = 10\ \Omega$，感抗 $X_L = 20\ \Omega$，容抗 $X_C = 30\ \Omega$，接在 $u = 100\sqrt2\cos(\omega t)\ \mathrm{V}$ 上。

（1）求电流相量 $\dot I$ 和有效值 $I$。
（2）求 $\dot U_R$、$\dot U_L$、$\dot U_C$。
（3）用 KVL 验证 $\dot U_R + \dot U_L + \dot U_C = \dot U$。

图 · R、L、C 串联

展开答案

（1） $Z = 10 + j(20 - 30) = 10 - j10\ \Omega$，$|Z| = 10\sqrt2 \approx 14.14\ \Omega$，$\varphi = -45^\circ$。

$$\dot I = \frac{100\angle0^\circ}{10 - j10} = \frac{100(10+j10)}{200} = 5 + j5 = 7.07\angle45^\circ\ \mathrm{A}$$

有效值 $I = 7.07\ \mathrm{A}$。电流超前电压 45°（容性）。

（2） $\dot U_R = 10(5+j5) = 50 + j50 = 70.7\angle45^\circ$

$\dot U_L = j20(5+j5) = -100 + j100 = 141.4\angle135^\circ$

$\dot U_C = -j30(5+j5) = 150 - j150 = 212.1\angle{-45^\circ}$

（3） 实部：$50 - 100 + 150 = 100$；虚部：$50 + 100 - 150 = 0$。

$$\dot U_R + \dot U_L + \dot U_C = 100 + j0 = 100\angle0^\circ = \dot U \quad✓$$

要点：$|\dot U_R| + |\dot U_L| + |\dot U_C| = 424 \ne 100$，但相量和确实是 100。幅值不能直接相加，永远是这条。

题 2（sin 换算）

串联电路：$R = 3\ \Omega$，$X_L = 4\ \Omega$。已知 $i = 4\sin(\omega t + 60^\circ)\ \mathrm{A}$（这里的 4 是幅值）。求电压 $u(t)$ 的时域表达式。

展开答案

第一步：sin 转 cos。

$$4\sin(\omega t + 60^\circ) = 4\cos(\omega t - 30^\circ)$$

第二步：转有效值相量。 幅值 4，有效值 $4/\sqrt2 = 2.83$，初相 $-30^\circ$：

$$\dot I = 2.83\angle{-30^\circ}\ \mathrm{A}$$

第三步：阻抗。 $Z = 3 + j4 = 5\angle53.13^\circ\ \Omega$。

第四步：求电压相量。

$$\dot U = Z\dot I = 5\angle53.13^\circ \times 2.83\angle{-30^\circ} = 14.15\angle23.13^\circ\ \mathrm{V}$$

第五步：转回时域。 有效值 14.15，幅值 $14.15\sqrt2 = 20$：

$$u(t) = 20\cos(\omega t + 23.13^\circ)\ \mathrm{V}$$

易错点：题目给的 4 是幅值不是有效值，转相量时要除以 $\sqrt2$；最后转回时域又要乘回去。这两步各错一次，答案会偏一倍。
