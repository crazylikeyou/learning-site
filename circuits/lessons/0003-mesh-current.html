第 3 课 · 回路电流法

当电路"网孔少、节点多"时，这套方法比节点法省方程。

2026-10-22 · 预计 18 分钟 · 承接第 2 课

一、什么时候该用它

节点法列 $n-1$ 个方程，回路法列的是独立回路数 $b - n + 1$。同样的电路，哪个数小就用哪个。

平面电路（能画在纸上不交叉）有一个好用的判断：有几个网孔，就是几个回路电流。两个网孔两个方程，三个网孔三个方程。

如果一道题画出来只有两三个"窗户"，而节点有五六个，那基本就是在提示你用回路法。

二、核心概念：回路电流不是支路电流

给每个网孔假设一个电流，沿着网孔环流一圈。这个量是数学上的中间量，不一定等于任何一条支路里真实流过的电流。

真实支路电流 = 这条支路上经过的回路电流的代数和。相邻网孔共用的那条支路，两个回路电流都经过它，方向相同就相加，方向相反就相减。

三、三条列式规则

规则一：所有回路电流统一取顺时针方向。这一步定了，后面互阻项才能一律写负号，不用每次判断。

规则二：自阻取正，互阻取负。

第 $k$ 个回路的方程：自阻乘本回路电流，减去与相邻回路之间的互阻乘那个回路的电流，等于本回路内电压源的代数和。

$$\sum R_{kk} I_k - \sum R_{km} I_m = \sum E_k$$

规则三：电压源看方向。沿回路绕行方向，从负极走向正极取正，从正极走向负极取负。

四、完整例子

电路：左网孔有 $R_1 = 2\ \Omega$（上边）和 $R_2 = 4\ \Omega$（中间共用），左侧支路是 $24\ \mathrm{V}$ 电压源；右网孔有 $R_3 = 2\ \Omega$（上边）和 $R_4 = 2\ \Omega$（右边）。设左网孔电流为 $I_1$、右网孔为 $I_2$，都取顺时针。

图 1 · 两个网孔，中间 $R_2$ 被两个回路共用

左网孔自阻 $R_1 + R_2 = 6\ \Omega$，与右网孔互阻 $R_2 = 4\ \Omega$，回路内电压源沿顺时针由负到正，记 $+24$：

$$6I_1 - 4I_2 = 24$$

右网孔自阻 $R_2 + R_3 + R_4 = 8\ \Omega$，互阻仍是 $4\ \Omega$，回路内没有电源：

$$-4I_1 + 8I_2 = 0$$

解这个方程组：第二式给 $I_1 = 2I_2$，代入第一式：$6(2I_2) - 4I_2 = 8I_2 = 24$，所以

$$I_2 = 3\ \mathrm{A}, \qquad I_1 = 6\ \mathrm{A}$$

中间共用支路上的真实电流是两个回路电流的代数和。$I_1$ 在 $R_2$ 里向下流，$I_2$ 在 $R_2$ 里向上流（它对右网孔顺时针，所以在共用支路上是往上），两者反向，取差：

$$I_{R2} = I_1 - I_2 = 6 - 3 = 3\ \mathrm{A，方向向下}$$

代回验算右网孔：$-4 \times 6 + 8 \times 3 = -24 + 24 = 0$，成立。

五、解答题

按考试格式做题，写出完整过程。做完再展开对照。

题 1（两问）

两个网孔，两回路电流均取顺时针。左侧支路是 $12\ \mathrm{V}$ 电压源（沿顺时针方向由负到正），$R_1 = 4\ \Omega$ 在左网孔上边、$R_2 = 2\ \Omega$ 为两网孔共用（中间支路），右网孔上边 $R_3 = 2\ \Omega$、右边 $R_4 = 2\ \Omega$。

（1）用回路电流法求 $I_1$、$I_2$。
（2）求中间共用支路的真实电流，并说明方向。

图 · 两个网孔，中间支路被两回路共用

展开答案

（1） 左网孔自阻 $R_1 + R_2 = 6\ \Omega$，互阻 $R_2 = 2\ \Omega$：

$$6I_1 - 2I_2 = 12$$

右网孔自阻 $R_2 + R_3 + R_4 = 6\ \Omega$，内部无电源：

$$-2I_1 + 6I_2 = 0 \;\Rightarrow\; I_1 = 3I_2$$

代入：$18I_2 - 2I_2 = 16I_2 = 12$，得 $I_2 = 0.75\ \mathrm{A}$，$I_1 = 2.25\ \mathrm{A}$。

（2） $I_1$ 在中间支路向下，$I_2$ 在中间支路向上，两者反向取差：

$$I_{R2} = 2.25 - 0.75 = 1.5\ \mathrm{A，方向向下}$$

易错点：共用支路方向要靠"各自顺时针"自己判断，别凭感觉斜着画。判断对了才知道是相加还是相减。
