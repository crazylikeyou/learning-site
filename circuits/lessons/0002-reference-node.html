第 2 课 · 参考节点

为什么节点法只能列 $n-1$ 个方程，以及"接地"到底在做什么。

2026-10-22 · 预计 15 分钟 · 对应摸底第 2 题

一、先破除一个印象

接地不是"给电路接一根线到大地"，也不是某种安全措施。在节点法里，它只做一件事：给所有节点电位定一个零点。

电位本身是相对的。把整条电路的电位同时抬高 100 V，每条支路上的电压差不变、电流不变、功率不变——物理上完全是同一个电路。所以"某点电位是 6 V"这句话本身没有绝对意义，只有 两点之间的差 才有意义。

既然整体平移不影响任何结果，我们就人为规定其中一点的电位为 0，其余节点的电位都相对它来写。这一点就是参考节点，习惯上画成接地符号。

二、于是方程个数就定了

假设电路有 $n$ 个节点。每个节点的电位都是未知量，但整体可以平移，所以真正独立的未知量只有 $n-1$ 个。选一个点当参考，剩下的 $n-1$ 个点各列一条 KCL，正好 $n-1$ 个方程解 $n-1$ 个未知量。

这就是为什么接地能"省掉一个未知量"——不是省了一条支路，也不是简化了计算，而是消掉了一个自由度。

三、标准三步

第一步，选参考节点。 优先选连接支路最多的点，或者电压源的一端。选得好，方程最简单。

第二步，对每个非参考节点列 KCL。 统一规定"流出该节点的电流之和为 0"。支路电流用 $(V_i - V_j)/R$ 表示。遇到理想电压源跨接在两个非参考节点之间，就要引入一个附加变量（这叫改进节点法），但期末通常不会在这个点上为难人。

第三步，解线性方程组。

四、一个完整例子

电路：理想电压源 $V_s = 10\ \mathrm{V}$ 接在节点 a 与地之间；$R_1 = 2\ \Omega$ 连接 a–b；$R_2 = 6\ \Omega$ 连接 b–地；$R_3 = 3\ \Omega$ 连接 b–c；$R_4 = 6\ \Omega$ 连接 c–地。

图 1 · a 点经电压源接地，b、c 为待求节点

共 4 个节点（a、b、c、地），选地为参考，未知量是 $V_a, V_b, V_c$ 三个。电压源把 $a$ 点和地直接连起来，所以 $V_a = 10\ \mathrm{V}$ 已知，真正要解的是 $V_b, V_c$ 两个。

对节点 b 列 KCL（流出为正）：

$$\frac{V_b - 10}{2} + \frac{V_b}{6} + \frac{V_b - V_c}{3} = 0$$

两边乘 6：$3(V_b - 10) + V_b + 2(V_b - V_c) = 0$，整理得 $3V_b - V_c = 15$。

常见疑问：三项都是加号，可"流出为正"不是应该有正有负吗？

加号来自写法统一，不是来自电流方向全一致。每条支路都写成 $\dfrac{V_b - V_j}{R}$，它的含义是"从 b 流向 j 的电流"。三项都按"离开 b"这个方向写，形状上自然一律是加号，加起来才构成 KCL：离开该节点的电流代数和为零。

正负藏在括号里。数值并不都为正——代入 $V_b = 6.43$ 后，第一项 $\dfrac{6.43-10}{2} = -1.79$ 是负数，表示 $R_1$ 上电流实际是从 a 流入 b，与假设的流出方向相反。负号就是"方向反了"的记号，KCL 完全允许。

$(-1.79) + 1.07 + 0.71 = 0$。若改成"流入为正"，三条支路都写成 $\dfrac{V_j - V_b}{R}$，整个方程乘 $-1$，解不变。关键是全篇统一，不是每项分别判断。

对节点 c 列 KCL：

$$\frac{V_c - V_b}{3} + \frac{V_c}{6} = 0$$

两边乘 6：$2(V_c - V_b) + V_c = 0$，整理得 $V_c = \frac{2}{3}V_b$。

代入第一式：$3V_b - \frac{2}{3}V_b = 15$，即 $\frac{7}{3}V_b = 15$，所以

$$V_b = \frac{45}{7} \approx 6.43\ \mathrm{V}, \qquad V_c = \frac{30}{7} \approx 4.29\ \mathrm{V}$$

代回验算：$\frac{6.43-10}{2} + \frac{6.43}{6} + \frac{6.43-4.29}{3} = -1.79 + 1.07 + 0.71 = 0$，成立。

五、解答题

按考试格式做题，写出完整过程。做完再展开对照。

题 1（两问）

$12\ \mathrm{V}$ 电压源接在节点 a 与地之间。$R_1 = 4\ \Omega$ 连接 a–b，$R_2 = 6\ \Omega$ 连接 b–地，$R_3 = 6\ \Omega$ 连接 b–c，$R_4 = 6\ \Omega$ 连接 c–地。

（1）用节点电压法求 $V_b$、$V_c$。
（2）求各支路电流（$R_1$ 到 $R_4$ 上的电流），并用 KCL 验算节点 b。

图 · 四节点电路，a 点经电压源接地

展开答案

（1） $V_a = 12\ \mathrm{V}$ 已知。对节点 b：

$$\frac{V_b - 12}{4} + \frac{V_b}{6} + \frac{V_b - V_c}{6} = 0$$

两边乘 12：$3(V_b - 12) + 2V_b + 2(V_b - V_c) = 0$，整理得 $7V_b - 2V_c = 36$。

对节点 c：$\dfrac{V_c - V_b}{6} + \dfrac{V_c}{6} = 0$，得 $2V_c = V_b$，即 $V_c = \dfrac{V_b}{2}$。

代入：$7V_b - V_b = 36$，$6V_b = 36$，所以

$$V_b = 6\ \mathrm{V}, \qquad V_c = 3\ \mathrm{V}$$

（2） 各支路电流（设方向由高电位到低电位）：

$I_1 = \dfrac{12 - 6}{4} = 1.5\ \mathrm{A}$（a→b）；$I_2 = \dfrac{6}{6} = 1\ \mathrm{A}$（b→地）；$I_3 = \dfrac{6-3}{6} = 0.5\ \mathrm{A}$（b→c）；$I_4 = \dfrac{3}{6} = 0.5\ \mathrm{A}$（c→地）。

验算节点 b：流入 $1.5\ \mathrm{A}$，流出 $1 + 0.5 = 1.5\ \mathrm{A}$ ✓

易错点：求出节点电位只是第一步，题目问"支路电流"就必须再算一遍。这一步在 3-19 那种题里是必答的。
