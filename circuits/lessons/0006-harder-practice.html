题 1 · 两个实际电压源并联 → 等效变换

两个实际电压源并联接在同一对端子上：$U_{s1} = 12\ \mathrm{V}$ 串 $R_1 = 2\ \Omega$；$U_{s2} = 6\ \mathrm{V}$ 串 $R_2 = 3\ \Omega$（两者正极同向）。求对外等效的电压源参数（等效电动势和内阻）。

图 · 两个实际电压源并接在同一对端子上

查看解法

两个电压源直接并联不能相加，必须先各自等效成电流源。

左支路：$I_{s1} = 12/2 = 6\ \mathrm{A}$，并联 $R_1 = 2\ \Omega$。
右支路：$I_{s2} = 6/3 = 2\ \mathrm{A}$，并联 $R_2 = 3\ \Omega$。

电流源同向，相加：$I_s = 6 + 2 = 8\ \mathrm{A}$；内阻并联：$R = \dfrac{2 \times 3}{2+3} = 1.2\ \Omega$。

再转回电压源：$U_s = I_s R = 8 \times 1.2 = 9.6\ \mathrm{V}$，内阻仍是 $1.2\ \Omega$。

要点：两个电压源并联是常见陷阱，直接相加得到 9 V 是错的。必须走"电压源→电流源→合并→再转回"这一圈。

题 2 · 三节点网络 → 节点电压法

参考地为 0。$12\ \mathrm{V}$ 电压源接在节点 1 与地之间（正极在 1）。$R_1 = 3\ \Omega$ 连接 1–2，$R_2 = 6\ \Omega$ 连接 2–地，$R_3 = 2\ \Omega$ 连接 2–3，$R_4 = 6\ \Omega$ 连接 3–地。$1\ \mathrm{A}$ 电流源注入节点 3。求 $V_2, V_3$。

图 · 节点 1 接 12 V 电压源，1 A 注入节点 3

查看解法

$V_1 = 12\ \mathrm{V}$ 已知（电压源直接接地）。

节点 2，流出为正：$\dfrac{V_2 - 12}{3} + \dfrac{V_2}{6} + \dfrac{V_2 - V_3}{2} = 0$，两边乘 6：$2(V_2-12) + V_2 + 3(V_2 - V_3) = 0$，整理得 $2V_2 - V_3 = 8$。

节点 3：$\dfrac{V_3 - V_2}{2} + \dfrac{V_3}{6} = 1$，两边乘 6：$3(V_3 - V_2) + V_3 = 6$，整理得 $4V_3 - 3V_2 = 6$。

由第一式 $V_3 = 2V_2 - 8$，代入第二式：$4(2V_2 - 8) - 3V_2 = 6 \Rightarrow 5V_2 = 38$。

$$V_2 = 7.6\ \mathrm{V}, \qquad V_3 = 7.2\ \mathrm{V}$$

验算节点 3：$\dfrac{7.2-7.6}{2} + \dfrac{7.2}{6} = -0.2 + 1.2 = 1\ \mathrm{A}$ ✓

题 3 · 电流源在外围支路的回路法 → 回路电流法

两个网孔。左侧网孔外侧支路上有一个 $2\ \mathrm{A}$ 电流源（方向与该网孔顺时针一致）。两网孔共用中间支路 $R_2 = 4\ \Omega$，右侧网孔还有 $R_3 = 6\ \Omega$。

求两个回路电流，以及中间共用支路上的真实电流。

图 · 电流源在左网孔外围支路

查看解法

关键观察：电流源只属于左网孔，它规定了该网孔的电流。左回路电流直接已知：$I_1 = 2\ \mathrm{A}$，不用列方程。

只需对右网孔列一条：$-R_2 I_1 + (R_2 + R_3)I_2 = 0$，即

$$-4 \times 2 + (4+6)I_2 = 0 \;\Rightarrow\; 10I_2 = 8 \;\Rightarrow\; I_2 = 0.8\ \mathrm{A}$$

中间共用支路：$I_1$ 在一个方向、$I_2$ 在相反方向，取差：

$$I_{R2} = |I_1 - I_2| = 2 - 0.8 = 1.2\ \mathrm{A}$$

要点：电流源在外围支路时，它所在网孔的电流是已知的，方程数直接少一个——这是回路法比节点法省事的地方。反过来，电压源跨在两个非地节点之间时才是节点法的麻烦。

题 4 · 双电源叠加 → 叠加定理

节点 b 与地之间：左侧 $R_1 = 3\ \Omega$ 串 $18\ \mathrm{V}$ 电压源（正极朝 b）；中间 $R_2 = 6\ \Omega$；右侧 $2\ \mathrm{A}$ 电流源注入 b。求 $V_b$。

图 · 三条并联支路，2 A 注入 b

查看解法

只留电压源（电流源断开）：$R_1$、$R_2$ 串联分压，$V_b' = 18 \times \dfrac{6}{3+6} = 12\ \mathrm{V}$。

只留电流源（电压源短接）：$R_1 \parallel R_2 = \dfrac{3 \times 6}{3+6} = 2\ \Omega$，$V_b'' = 2 \times 2 = 4\ \mathrm{V}$。

两者方向一致，相加：$V_b = 12 + 4 = 16\ \mathrm{V}$。

节点法验算：$\dfrac{V_b - 18}{3} + \dfrac{V_b}{6} = 2$，乘 6 得 $2V_b - 36 + V_b = 12$，$3V_b = 48$，$V_b = 16\ \mathrm{V}$ ✓

题 5 · 戴维南 + 最大功率 → 电路定理

$12\ \mathrm{V}$ 电压源经 $R_1 = 4\ \Omega$ 接到节点 b，$R_2 = 6\ \Omega$ 由 b 接地。在 b 与地之间外接可变负载 $R_L$。求：(1) 从 $R_L$ 看进去的戴维南等效；(2) $R_L$ 取多少时获得最大功率，功率是多少。

图 · 从 b 与地之间接可变负载 R_L

查看解法

开路电压：$R_L$ 断开时，$R_1$、$R_2$ 串联，$U_{oc} = 12 \times \dfrac{6}{4+6} = 7.2\ \mathrm{V}$。

等效内阻：电压源置零（短接），从 b 与地看进去是 $R_1 \parallel R_2 = \dfrac{4 \times 6}{4+6} = 2.4\ \Omega$。

最大功率条件：$R_L = R_{eq} = 2.4\ \Omega$。

$$P_{max} = \frac{U_{oc}^2}{4R_{eq}} = \frac{7.2^2}{4 \times 2.4} = \frac{51.84}{9.6} = 5.4\ \mathrm{W}$$

要点：最大功率公式的分母是 $4R_{eq}$，不是 $R_{eq}$。另外注意这题要求"从负载看进去"，所以求内阻时要把负载移走，别把 $R_L$ 一起算进去。

题 6 · 容性负载的相量计算 → 相量法与功率

串联电路：$R = 6\ \Omega$，容抗 $X_C = 8\ \Omega$，接在 $\dot{U} = 100\angle 0^\circ\ \mathrm{V}$（有效值）上。求电流相量、有效值、有功功率、无功功率、视在功率和功率因数，并说明电流超前还是滞后。

图 · R 与 C 串联

查看解法

阻抗 $Z = 6 - j8\ \Omega$（容性取负），$|Z| = \sqrt{36+64} = 10\ \Omega$，阻抗角 $\varphi = \arctan\dfrac{-8}{6} \approx -53.13^\circ$。

$$\dot{I} = \frac{100\angle 0^\circ}{10\angle{-53.13^\circ}} = 10\angle{53.13^\circ}\ \mathrm{A}$$

电流有效值 $I = 10\ \mathrm{A}$，相角为正，所以电流超前电压 53.13°（容性电路的特征）。

有功功率 $P = I^2R = 100 \times 6 = 600\ \mathrm{W}$。
无功功率 $Q = -I^2X_C = -100 \times 8 = -800\ \mathrm{var}$（容性取负）。
视在功率 $S = UI = 100 \times 10 = 1000\ \mathrm{VA}$。

功率因数 $\cos 53.13^\circ = 0.6$（超前）。

校验：$S^2 = P^2 + Q^2$，$10^6 = 3.6 \times 10^5 + 6.4 \times 10^5$ ✓

要点：容性电路的无功功率带负号、功率因数写"超前"；感性则相反。这一步写错，功率题基本没分。
