第 5 课 · 电源置零

电压源置零是短路，电流源置零是开路——以及为什么必须是这样。

2026-10-22 · 预计 15 分钟 · 对应摸底第 6 题

一、规则只有两条，但要说清理由

电压源置零 → 用导线短接。 电压源的使命是维持两端电压等于某个值。把它"关掉"，等于让它维持的电压变成 0。两端电压为 0 的理想元件就是一根导线。

电流源置零 → 断开该支路。 电流源的使命是维持流过它的电流等于某个值。关掉它，等于让它流过的电流变成 0。电流恒为 0 的支路，等于不存在。

共同点是：置零不是"删掉这个元件"，而是把它的输出强制设为零，再看这是什么元件。电压为 0 是导线，电流为 0 是断路。

这两个记反的后果很严重：电压源错当断路，电路少了一条通路，等效电阻算错，后面全错；电流源错当短路，直接制造出一堆不存在的电流。

二、叠加定理

线性电路里有多个独立源时：每次只留一个源工作，其余全部置零，算出该源单独作用时的响应；最后把所有响应代数相加。

三条限制必须记住：

只能用于线性电路。 含二极管的电路不能叠加。

每个源单独作用时，其他源要置零，不是删除。 电路拓扑必须保持完整。

功率不能直接叠加。 因为 $P = I^2R$ 是二次关系。必须先叠加电流或电压，再算功率。

考试动作：每个源单独画一张分图。

老师笔记里 4-2 那道含三个源的题，解法就是画了 三张独立电路图：(a) 只留 136 V、(b) 只留 50 V、(c) 只留 3 A，其余源按规则置零。每张图上只算一个分量，最后代数相加。

为什么一定要画：不画就容易在一张图上"顺手"把别的源也算进去。三张图各自独立，反而更快、更不容易错。阅卷也是按三张图给分。

三、完整例子

节点 b 与地之间接三条支路：左侧 $R_1 = 2\ \Omega$ 串 $12\ \mathrm{V}$ 电压源（正极朝 b），中间 $R_2 = 6\ \Omega$，右侧 $3\ \mathrm{A}$ 电流源（电流注入 b）。求 $V_b$。

图 1 · 三条并联支路，电源方向：电压源正极朝上，电流源向上注入 b

第一步：只留电压源，电流源置零——也就是断开右支路。

此时是 $R_1$ 与 $R_2$ 串联接在 12 V 两端，$V_b$ 是 $R_2$ 上的电压：

$$V_b' = 12 \times \frac{6}{2+6} = 9\ \mathrm{V}$$

第二步：只留电流源，电压源置零——也就是把左支路短接成导线，只剩 $R_1$。

现在 $R_1$ 与 $R_2$ 并联，$3\ \mathrm{A}$ 全部注入这个并联电阻：

$$R_1 \parallel R_2 = \frac{2 \times 6}{2+6} = 1.5\ \Omega \qquad V_b'' = 3 \times 1.5 = 4.5\ \mathrm{V}$$

第三步：代数相加。 两个分量方向一致（都是让 b 点电位升高），取正号：

$$V_b = 9 + 4.5 = 13.5\ \mathrm{V}$$

验算：直接用节点法写一条方程，把电流源当成注入 b 的 3 A：

$$\frac{V_b - 12}{2} + \frac{V_b}{6} = 3 \;\Longrightarrow\; 3V_b - 36 + V_b = 18 \;\Longrightarrow\; 4V_b = 54 \;\Longrightarrow\; V_b = 13.5\ \mathrm{V}$$

两个方法对上了。这个验算建议你考试时也做——叠加容易在符号上翻车，用节点法复核一遍最稳。

四、解答题

按考试格式做题，写出完整过程。做完再展开对照。

题 1（三问）

节点 b 与地之间接三条支路：左侧 $R_1 = 6\ \Omega$ 串 $30\ \mathrm{V}$ 电压源（正极朝 b）；中间 $R_2 = 3\ \Omega$；右侧 $4\ \mathrm{A}$ 电流源注入 b。

（1）用叠加定理求 $V_b$，要求分别写出两个分量及方向判断。
（2）用节点电压法验算。
（3）若把电流源改为从 b 流出 $4\ \mathrm{A}$，$V_b$ 变成多少？

图 · 三条并联支路，电压源正极朝 b，电流源注入 b

展开答案

（1） 只留电压源（电流源断开）：$R_1$、$R_2$ 串联分压，$V_b' = 30 \times \dfrac{3}{6+3} = 10\ \mathrm{V}$。

只留电流源（电压源短接）：$R_1 \parallel R_2 = \dfrac{6 \times 3}{9} = 2\ \Omega$，$V_b'' = 4 \times 2 = 8\ \mathrm{V}$。

两者都使 b 点电位升高，同号相加：$V_b = 10 + 8 = 18\ \mathrm{V}$。

（2） $\dfrac{V_b - 30}{6} + \dfrac{V_b}{3} = 4$，两边乘 6：$V_b - 30 + 2V_b = 24$，$3V_b = 54$，$V_b = 18\ \mathrm{V}$ ✓

（3） 电流源反向后，它对应的分量变号：$V_b = 10 - 8 = 2\ \mathrm{V}$。

用节点法验算：$\dfrac{V_b - 30}{6} + \dfrac{V_b}{3} = -4$，乘 6 得 $3V_b - 30 = -24$，$V_b = 2\ \mathrm{V}$ ✓

易错点：电流源方向一改，是"从 b 流出"，在节点方程里就该写 $-4$。符号错了这道题整题报废，所以叠加完一定要用节点法验一遍。
