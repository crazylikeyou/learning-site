第 7 课 · 戴维南与诺顿

把一个复杂的含源网络，压成一个电压源加一个电阻。

2026-10-22 · 预计 20 分钟 · 只用置零法求内阻

一、定理在说什么

任何线性含源一端口网络，对外部来说，都可以等效成：

一个电压源 $U_{oc}$ 串联一个电阻 $R_{eq}$ —— 这就是戴维南等效。

或者等效成一个电流源 $I_{sc}$ 并联一个电阻 $R_{eq}$ —— 这是诺顿等效。

两者是同一件事的两种画法，可以互相转换，关系就是欧姆定律：

$$U_{oc} = I_{sc} \cdot R_{eq} \qquad\text{或}\qquad I_{sc} = \frac{U_{oc}}{R_{eq}}$$

"一端口"的意思是：这个网络对外只伸出两个接线端子（a、b）。你要把它变成对外等效的简单模型，外部电路怎么看都觉得没变化。

二、三个量，三种求法

$U_{oc}$（开路电压）：把负载摘掉，让端口悬空，测两端电压。注意悬空意味着端口支路没有电流，但网络内部的电流照常存在。

$I_{sc}$（短路电流）：把端口直接用导线短接，测流过这根短线的电流。

$R_{eq}$（等效内阻）：把网络内所有独立源置零——电压源短接、电流源断开——然后从端口看进去算串并联。

三个量知道其中两个，第三个用关系式算出来。最常用的是 $U_{oc}$ 加 $R_{eq}$。

置零求内阻这一步，就是上一课的内容。上一课没吃透，这一课一定卡——两课是连着的。

三、完整例子

电路：$24\ \mathrm{V}$ 电压源经 $R_1 = 6\ \Omega$ 接到节点 a；a 经 $R_2 = 3\ \Omega$ 接地；a 经 $R_3 = 2\ \Omega$ 接到节点 b；b 经 $R_4 = 4\ \Omega$ 接地。求从 b 与地之间看进去的戴维南等效。

图 1 · 从 b 与地之间看进去

第一步：求开路电压 $U_{oc}$。 端口悬空，$R_4$ 上没有电流？不对——要小心这里。

端口悬空指的是 b 与地之间除了 $R_4$ 以外没有别的连接。$R_4$ 本身还在，所以 b 点电位就是 $R_4$ 上的电压。用分压做：

从 a 往右看，$R_3$ 与 $R_4$ 串联后与 $R_2$ 并联：$R_2 \parallel (R_3+R_4) = 3 \parallel 6 = 2\ \Omega$。

再与 $R_1$ 串联：总电阻 $6 + 2 = 8\ \Omega$，主电流 $I = 24/8 = 3\ \mathrm{A}$。

$V_a = I \times 2 = 6\ \mathrm{V}$（并联部分的分压），再在 $R_3$、$R_4$ 之间分一次：

$$U_{oc} = V_b = 6 \times \frac{4}{2+4} = 4\ \mathrm{V}$$

第二步：求等效内阻 $R_{eq}$。 把 24 V 电压源短接。此时从 b 与地看进去：

b 点有两条路到地——一条直接经 $R_4 = 4\ \Omega$；另一条经 $R_3 = 2\ \Omega$ 到 a，而从 a 到地有 $R_2 = 3\ \Omega$ 和 $R_1 = 6\ \Omega$ 并联。

$$R_1 \parallel R_2 = \frac{6 \times 3}{6+3} = 2\ \Omega,\qquad 2 + R_3 = 4\ \Omega$$

$$R_{eq} = 4 \parallel 4 = 2\ \Omega$$

第三步：短路电流。

$$I_{sc} = \frac{U_{oc}}{R_{eq}} = \frac{4}{2} = 2\ \mathrm{A}$$

所以这个网络对外就相当于：$4\ \mathrm{V}$ 电压源串联 $2\ \Omega$ 电阻。接任何负载，都可以用这两个数算，不用再管里面那四个电阻。

四、顺带复习最大功率

负载电阻等于内阻时获得最大功率：$R_L = R_{eq} = 2\ \Omega$。

$$P_{max} = \frac{U_{oc}^2}{4R_{eq}} = \frac{16}{8} = 2\ \mathrm{W}$$

分母是 $4R_{eq}$——这是最常写错的地方，别写成 $R_{eq}$。

答题纪律：最后一定要画出两种等效电路。

老师笔记 4-9 的要求是"求戴维宁或诺顿等效电路"——注意是电路，不只是两个数。答案要包含：

① 戴维南：一个电压源 $U_{oc}$ 串联一个电阻 $R_{eq}$，标出正负极；

② 诺顿：一个电流源 $I_{sc}$ 并联同一个 $R_{eq}$，标出电流方向。

只写"$U_{oc}=0.5$ V，$R_{eq}=2$ Ω"会丢图分。两个图之间的关系是 $I_{sc}=U_{oc}/R_{eq}$，画出其中一个就能顺手画出另一个。

五、解答题（按考试格式）

下面的题按你原题的样式出：一个问题下面挂两个小问，要求写出完整过程。先自己在纸上做，做完再展开对照。

题 1（三问）

沿用本课例题的电路：$24\ \mathrm{V}$ 电压源经 $R_1 = 6\ \Omega$ 接节点 a，a 经 $R_2 = 3\ \Omega$ 接地，a 经 $R_3 = 2\ \Omega$ 接节点 b，b 经 $R_4 = 4\ \Omega$ 接地。

（1）求从 b 与地之间看进去的戴维南等效电路。
（2）若在 b 与地之间接一个 $2\ \Omega$ 的负载，求流过负载的电流。
（3）负载电阻取何值时获得的功率最大？最大功率是多少？

展开答案

（1） 开路电压：$R_3$、$R_4$ 串联后与 $R_2$ 并联得 $2\ \Omega$，总电阻 $6+2=8\ \Omega$，主电流 $3\ \mathrm{A}$，$V_a = 6\ \mathrm{V}$，再分压 $U_{oc} = 6 \times \frac{4}{2+4} = 4\ \mathrm{V}$。

等效内阻：电压源短接，$R_1 \parallel R_2 = 2\ \Omega$，加 $R_3$ 得 $4\ \Omega$，再与 $R_4$ 并联得 $R_{eq} = 2\ \Omega$。

所以等效为 $4\ \mathrm{V}$ 串联 $2\ \Omega$。

（2） 接 $2\ \Omega$ 负载后，总电阻 $2+2=4\ \Omega$，$I_L = \dfrac{4}{2+2} = 1\ \mathrm{A}$。

（3） 当 $R_L = R_{eq} = 2\ \Omega$ 时功率最大：$P_{max} = \dfrac{U_{oc}^2}{4R_{eq}} = \dfrac{16}{8} = 2\ \mathrm{W}$。

易错点：（2）里分母是 $R_{eq} + R_L$，别只写 $R_L$；（3）的分母是 $4R_{eq}$，不是 $R_{eq}$。

题 2（叠加，两问）

节点 b 与地之间接三条支路：左侧 $R_1 = 4\ \Omega$ 串 $24\ \mathrm{V}$ 电压源（正极朝 b）；中间 $R_2 = 12\ \Omega$；右侧 $3\ \mathrm{A}$ 电流源注入 b。

（1）用叠加定理求 $V_b$，要求分别写出两个分量。
（2）用节点电压法验算，两次结果必须一致。

展开答案

（1）只留电压源（电流源断开）：$R_1$、$R_2$ 串联分压，$V_b' = 24 \times \dfrac{12}{4+12} = 18\ \mathrm{V}$。

只留电流源（电压源短接）：$R_1 \parallel R_2 = \dfrac{4 \times 12}{4+12} = 3\ \Omega$，$V_b'' = 3 \times 3 = 9\ \mathrm{V}$。

方向一致，相加：$V_b = 18 + 9 = 27\ \mathrm{V}$。

（2）节点法：$\dfrac{V_b - 24}{4} + \dfrac{V_b}{12} = 3$，两边乘 12：$3V_b - 72 + V_b = 36$，$4V_b = 108$，$V_b = 27\ \mathrm{V}$ ✓
